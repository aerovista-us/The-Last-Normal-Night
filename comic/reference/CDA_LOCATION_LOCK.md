# CDA Location Lock
## EchoStory: The Last Normal Night

This file defines the geographic-continuity rules for Coeur d'Alene in the comic adaptation.

## Core rule

**The fractured world is the same Coeur d'Alene, not a newly invented city.**

The lake, Tubbs Hill, downtown grid, Sherman Avenue corridor, McEuen Park, the resort/marina relationship, waterfront approaches, major street orientation, and recognizable landmark massing must remain geographically coherent between normal and fractured versions.

Reality changes details before it changes geography.

## Normal-world reference priority

Use real-location references supplied for the project as the primary visual basis for:

- downtown street proportions
- Sherman Avenue storefront scale
- McEuen Park and waterfront relationship
- Tubbs Hill position and silhouette
- Coeur d'Alene Resort and marina massing
- city clock / intersection context
- lake shoreline and dock orientation
- residential and commercial transition around downtown
- local bar and storefront scale
- street furniture, lamps, signals, road markings, sidewalks, parking and alleys

Generated location boards are secondary aids. If a generated board contradicts the real-location references, the real reference wins.

## Fracture rule

Before the story deliberately escalates later, altered CDA should preserve the same base geography and introduce controlled contradictions such as:

- one building where the protagonist remembers an empty lot
- one missing building
- a facade with an impossible earlier history
- a road that feels subtly too long
- a storefront or sign that should not exist
- a direction sign pointing incorrectly
- a clock or digital display disagreeing with nearby time
- a landmark detail shifted or renamed while its location remains stable
- traffic, signal, or pedestrian behavior that feels mathematically wrong
- lake markers or navigation references that conflict with memory

Do not casually relocate the resort, marina, lake, Tubbs Hill, McEuen Park, or major downtown streets merely to make an image composition more dramatic.

## Visual philosophy

The audience should be able to recognize the location first and notice the contradiction second.

**One wrong detail in a real place is stronger than a completely fictional skyline.**

## EP1 specific rule

Pages 1–13 are overwhelmingly grounded in recognizable CDA. The first rupture may distort alignment and timing, but it should not replace the city with fantasy architecture.

After the rupture, the environment may contain altered-history details, but the protagonist must still be able to orient himself by the same lake, mountains, downtown streets and major landmarks.

## Production rule

When generating or assembling page art:

1. Start from real-location composition and geography.
2. Preserve landmark relationships.
3. Add story anomalies only where the script calls for them.
4. Avoid invented mountains, altered shoreline geometry, relocated resort structures, or dramatically rearranged streets.
5. Use generated environment masters only as mood/lighting references when their geography is approximate.

This rule applies to all future issues unless the story bible explicitly establishes a reality where large-scale geography has changed.
