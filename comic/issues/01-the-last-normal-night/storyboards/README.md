## Rules

- These proofs are **not** final publishable pages.
- Final art should be generated/sourced per panel rectangle, except the 14–15 spread which is authored as one composition.
- Generated panel art contains no final story lettering.
- Temporary text in these proofs exists only to prove balloon/UI/SFX space.
- `script.md` remains authoritative for dialogue, action and reveal order.
- `focus-regions.json` remains authoritative for Rack mobile reading order.
- Real CDA references and `comic/reference/CDA_LOCATION_LOCK.md` override invented location geometry.
